# Ambrad Consulting website (digital and AI transformation)

Source for www.ambradconsulting.uk, served by GitHub Pages from the `main` branch root.
This is Ambrad Consulting's digital and AI transformation site. The engineering and planning site is www.ambradconsulting.com (repo `ambrad-consulting`).

- `index.html` home page (process-led AI transformation, three practices).
- Service pages: `systems-engineering.html`, `operational-excellence.html`, `ai-consultancy.html`. (Asset management and PFI contract reviews live on ambradconsulting.com.)
- `department-ai-plan.html` the Department AI Plan landing page (no prices, no Ownet branding).
- `assets/` shared stylesheet and the coral hexagon mark.

Changes to `main` publish straight to the live site.
